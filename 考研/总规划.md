## 数学

本来计划 8 月底完成一轮基础，现在还剩 15 天，还剩下 21 讲的内容。时间压力很大，回到家里浪费了差不多一个半月的时间。**我似乎明白了一件事**，自从离开了学校，自己的控制力基本为 0，基本自制力都失去了。

按理说，以我的能力不可能会这样，但回到家后，我的第一感觉就是无聊和空虚，因为看不到那些压力，看不到那些努力学习的同学，让我下意识地以为自己在放松。此外，最重要的是无人可以聊天，没什么好说话的，没什么娱乐措施，感觉到一种特别压抑的气息。想说话不知道和谁说，在网上聊天也没有同龄人，和 AI 聊天感觉自己是个傻子，因为我比较了解 AI，知道这是个概率机器，就顿时感觉没什么意思。

想要在这么点时间完成复习，真得舍弃小点知识，快速过掉大部分知识，或者知识体系。

**数学的复习路线调整为**：

高数：

```
一元积分学计算和应用 -> 无穷级数 -> 多元函数微分学 -> 微分方程 -> 二重积分、三重积分 -> 多元函数积分学
```

线代：

```
行列式 -> 矩阵的计算 -> 向量 -> 向量组线性相关性 -> 线性方程组计算 -> 特征值和特征向量 -> 实二次型
```

概率论：

```
随机事件 -> 一维随机变量分布 -> 多维随机变量分布 -> 随机变量的统计特征（均值、方差、协方差） -> 大数定律 -> 数理统计(三大分布)
```

但更重要的是计算和练习的问题，一轮我打算每一讲这么做：

1. 学习基础的知识点，对于那些死记硬背的规律和结论，如果不是基础的，打个记号先标记在哪一页，二轮再说
2. 当天如果弄不完某一讲的所有内容，先把练习题里有关已经学到的知识点的题写了
3. 晚上花时间问 AI 不懂的题和写点笔记和错题
4. 每完成一个模块的内容，回顾错题。例如一元积分的，级数的。

## 英语

英语的问题是，背单词太枯燥。因为光是盯着单词和中文释义看是很折磨的，**我更喜欢有例句的形式**。

所以我打算改为：

每天背的单词不变，一天一个 unit。但是需要改变记忆方式，因为基本都是新的词汇，真需要用例子来记忆，而不是盯着中文意思看。

一个单词对应一个例句。

此外，需要开始考研真题的阅读了，起码得一天一篇，把看不懂的单词也记录下来（按例句记录），然后重复记忆。我都快忘了高中时训练的英语阅读技巧了。



**怎么说你也是省级重点高中前一百级别的精英选手，为什么会落得这种情况？真得好好反思你自己的所作所为了**

## 专业课

基于自己还有一些 801 通信原理的基础，801 考的内容需要问问导员怎么复习了。但基本的知识点复习应该如下：

- 第二章：确定性信号分析

  1. 傅里叶级数变换
  2. 能量谱密度和功率谱密度 $P_n(f)$ 的计算
  3. 带通滤波器、带通信号的等效基带表示
  4. 希尔伯特变换与复包络，参考载波
  5. 确定信号的自相关函数与维纳辛钦定理
- 第三章：随机信号分析

  1. 随机信号的统计特征与功率谱密度、平均功率计算（可以注意统计特征与物理术语名称的统一，例如均值为直流分量）
  2. 平稳过程、零均值平稳过程、广义平稳
  3. 维纳辛钦定律
  4. 平稳随机过程通过线性时不变 (LTI) 系统的性质
  5. 加性高斯白噪声 AWGN 过高通、低通、带通滤波器前后的 PSD 和平均功率的计算
  6. 窄性 AWGN 的计算和正交表达式：
  7. 高斯分布、Q 函数和 erfc 函数的变换
  8. LTI 系统级联下的传递函数表达式 $H(f) = H_1(f)*H_2(f)$
  9. 匹配滤波器
- 第四章：模拟调制
  1. DSB-SC、AM、FM、PM、SSB 信号的表达式、调制与解调的过程和计算
  2. 卡松公式
  3. 相干解调的抗噪声性能分析
  4. 模拟信号的包络调制和解调

- 第五章：数字基带传输
  1. PAM 调制定义和计算
  2. NRZ/RZ 码型判断和功率谱计算
  3. BER 分析
  4. 在 AWGN 信道下的 PAM 信号的最佳接收机计算和抽样判决
  5. 无 ISI 传输和奈奎斯特采样准则
  6. 在 AWGN 信道下的最佳基带传输系统，根升余弦滤波器
  7. 眼图和信道均衡

- 第六章：数字频带传输（将基带信号调制到其他频段）
  1. BPSK、2FSK、OOK 的原理，相干解调的最佳接收机分析
  2. DPSK 原理
  3. QPSK 的原理、相干解调、功率谱密度
  4. OQPSK的原理
  5. 星座图、16QAM、MAL准则与ML准则的判决域划分，最小欧式距离计算
  6. MASK、MPSK、MQAM、MFSK 基本原理、星座图、系统框图

- 第七章：信源编码和量化
  1. 量化的计算（纯概率论）
  2. A律13折线
